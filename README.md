# ImageEditor - application for editing images

![Status](https://img.shields.io/badge/status-Archived-yellow)
![Platform](https://img.shields.io/badge/platform-Windows%20-blue)
![DotNet](https://img.shields.io/badge/.NET-idk-purple)
![License](https://img.shields.io/badge/license-MIT%20with%20Attribution-green)

ImageEditor is a pretty simple image editor built around C++ and Windows Forms (thats the same Windows Forms as C# has, but with some lang-specific stuff)
Have an essential set of tools: brush, fill tool, selection, smooth brush and color picker.

It was moved from one of my old project archives.
I need to somehow show that I know what Windows Forms is, so that's it. And it has no vibecoded frontend, what's pretty awful.
